# Godot-Lab-Assignments-

My IVGD Lab Assignment



Lab 1



Gojo and Toji are about to start a fight in a port on a sunny day as seagulls are flying in the background. I added 2 sprites for the two characters from Jujutsu Kaisen. Then I added the background. Finally, I added a seagull, converted it into a scene and added multiple instances of the same scene.

I enjoyed working on this lab, it was easy with the in class teaching on how to make scenes and move stuff around. The hardest thing was choosing the sprites from google and think about what scene I wanted to add.
